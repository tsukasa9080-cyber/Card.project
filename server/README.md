# Card Meaning Server

Mac上のOllamaで単語の意味を生成します。OpenAI APIキーやAPI利用料は不要です。
Node.js 20以降を使用してください。

## 初回準備

Ollamaをインストール・起動して、モデルを取得します。

```sh
ollama pull qwen3:4b
cd server
npm install
```

`.env` がない場合は `.env.example` をコピーして `.env` を作成してください。
既存の `.env` を上書きする必要はありません。

## 起動

Ollamaを起動した状態で、serverフォルダから実行します。

```sh
npm start
```

ターミナルを開いたまま、XcodeからiPhoneシミュレータを実行します。
アプリの「生成AIサーバーURLを設定」で `http://127.0.0.1:3000` を保存し、表面に単語を入力して「生成」を押してください。
初回はモデルの読み込みに時間がかかります。
停止はControl+C、再開はnpm startです。

`http://127.0.0.1:3000/health` はサーバーの起動確認です。AIの生成確認はアプリで行ってください。

## 動作条件

既定ではMac自身からの接続だけを受け付けます。実機で試す場合はMacとiPhoneを同じ信頼できるWi-Fiに接続し、`.env` に `HOST=MacのWi-FiのIPアドレス` を設定してサーバーを再起動してください。アプリのサーバーURLも `http://MacのWi-FiのIPアドレス:3000` に変更し、ローカルネットワークへのアクセスを許可します。USB接続だけでは接続できません。IPが変わった場合は両方の設定を更新してください。シミュレータからも設定したMacのアドレスを使用します。
この開発用サーバーには認証がありません。インターネットに公開せず、実機テストに使用してください。App Storeで配布する場合は別の接続・公開設計が必要です。
AIを使う間はMac・Ollama・このサーバーを動かしてください。
